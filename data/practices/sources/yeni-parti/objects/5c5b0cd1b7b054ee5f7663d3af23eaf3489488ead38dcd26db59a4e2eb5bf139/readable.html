        <p><a href="/tag/yeni-parti-samsun/" class="content-tag-link" style="color: var(--red); font-weight: 600; text-decoration: underline;">Yeni Parti Samsun</a> İl Başkanlığı için gerçekleştirilen heyecan dolu ön seçimin resmi sonuçları açıklandı. Samsun'un 17 ilçesinde kurulan sandıklarda gerçekleştirilen oylama sonucunda <a href="/tag/mehmet-ozdag/" class="content-tag-link" style="color: var(--red); font-weight: 600; text-decoration: underline;">Mehmet Özdağ</a> <strong>3 bin 999 oy</strong> alarak il başkanlığı ön seçimini kazanırken, rakibi <a href="/tag/turgay-ozcelik/" class="content-tag-link" style="color: var(--red); font-weight: 600; text-decoration: underline;">Turgay Özçelik</a> <strong>3 bin 796 oyda</strong> kaldı. İki aday arasında yalnızca 203 oyluk kritik bir fark oluşurken, ilçelerdeki oy dağılımı seçimin düğümünü çözen ana faktör oldu.</p>

<h2>Seçimin Kaderini <a href="/tag/atakum/" class="content-tag-link" style="color: var(--red); font-weight: 600; text-decoration: underline;">Atakum</a> Belirledi</h2>
<p>Seçim yarışında dengeleri değiştiren ve nihai sonucu tayin eden en belirleyici ilçe Atakum oldu. Mehmet Özdağ, Atakum'da <strong>1.254 oy</strong> alırken, Turgay Özçelik <strong>812 oyda</strong> kaldı. Özdağ'ın sadece Atakum'da elde ettiği 442 oyluk net üstünlük, il genelindeki 203 oyluk galibiyet farkının iki katını aşarak zaferin kapısını araladı.</p>
<p>Atakum'da kurulan 10 sandığın 9'unda rakibini geride bırakmayı başaran Özdağ, ilçeden aldığı güçlü destekle genel toplamda zirveye yerleşti.</p>

<h2>Turgay Özçelik 8 İlçede Öne Çıktı</h2>
<p>Seçimi az bir farkla kaybeden Turgay Özçelik ise Samsun'un 8 ilçesinde rakibinden daha yüksek oy alarak güçlü bir performans sergiledi. Özçelik'in en yüksek farkı yakaladığı ilçe Tekkeköy oldu.</p>
<p>Tekkeköy'de 387 oy alan Özçelik, 113 oyda kalan rakibi Özdağ'a 274 oy fark attı. Özçelik ayrıca Havza'da 252'ye 51, Çarşamba'da 420'ye 285 ve kentin en büyük ilçelerinden İlkadım'da 1.020'ye 909 oyla üstünlük sağladı. 19 Mayıs, Canik, Kavak ve Salıpazarı ilçelerinde de seçimi önde tamamlayan Özçelik'in bu başarısı, Atakum'daki farkı kapatmaya yetmedi.</p>

<h2>Mehmet Özdağ 9 İlçede Sandıktan Birinci Çıktı</h2>
<p>Ön seçimin galibi Mehmet Özdağ; Atakum'un yanı sıra Alaçam, Asarcık, Ayvacık, Bafra, Ladik, Terme, Vezirköprü ve Yakakent olmak üzere toplam 9 ilçede rakibini geride bıraktı.</p>
<p>Özdağ, Atakum'un ardından en büyük farkı Alaçam'da yakaladı. Alaçam'da 243 oy alan Özdağ, 61 oyda kalan rakibine 182 oy fark attı. Bafra'da 281'e 193, Vezirköprü'de ise 169'a 103 oyla önde tamamlayan Özdağ, dengeli oy dağılımıyla ipi göğüsledi.</p>

<h2>203 Oy Farkla İl Başkanı Seçildi</h2>

                  customGain: customGain,
                  videoSource: videoSource,
                  videoGain: videoGain,
                  destination: dest
                };
              }
              
              if (window.lskAudioGraph.context.state === 'suspended') {
                window.lskAudioGraph.context.resume();
              }
              
              // Reset / Set dynamic volumes
              if (isUseOriginalSound) {
                // Background music and custom music fully muted
                window.lskAudioGraph.bgGain.gain.setValueAtTime(0.0, window.lskAudioGraph.context.currentTime);
                window.lskAudioGraph.customGain.gain.setValueAtTime(0.0, window.lskAudioGraph.context.currentTime);
                // Video sound at full volume
                window.lskAudioGraph.videoGain.gain.setValueAtTime(1.0, window.lskAudioGraph.context.currentTime);
              } else if (isMixBackgroundLow) {
                // Background music at 5% volume, custom audio at 5% volume
                window.lskAudioGraph.bgGain.gain.setValueAtTime(0.05, window.lskAudioGraph.context.currentTime);
                window.lskAudioGraph.customGain.gain.setValueAtTime(isDefaultAudio ? 0.0 : 0.05, window.lskAudioGraph.context.currentTime);
                // Video sound at full volume
                window.lskAudioGraph.videoGain.gain.setValueAtTime(1.0, window.lskAudioGraph.context.currentTime);
              } else {
                if (isDefaultAudio) {
                  // Background music at full volume, custom audio muted
                  window.lskAudioGraph.bgGain.gain.setValueAtTime(1.0, window.lskAudioGraph.context.currentTime);
                  window.lskAudioGraph.customGain.gain.setValueAtTime(0.0, window.lskAudioGraph.context.currentTime);
                } else {
                  // Background music starts at 100% volume
                  window.lskAudioGraph.bgGain.gain.setValueAtTime(1.0, window.lskAudioGraph.context.currentTime);
                  // Duck background music smoothly by 85% (volume to 0.15) at 1.0 second, fading over 0.2s
                  window.lskAudioGraph.bgGain.gain.setValueAtTime(1.0, window.lskAudioGraph.context.currentTime + 1.0);
                  window.lskAudioGraph.bgGain.gain.linearRampToValueAtTime(0.15, window.lskAudioGraph.context.currentTime + 1.2);
                  
                  // Custom audio track at 100% volume
                  window.lskAudioGraph.customGain.gain.setValueAtTime(1.0, window.lskAudioGraph.context.currentTime);
                }
                
                // Video sound mixing
                if (isVideoLoaded && !isVideoSoundMuted) {
                  window.lskAudioGraph.videoGain.gain.setValueAtTime(1.0, window.lskAudioGraph.context.currentTime);
                } else {
                  window.lskAudioGraph.videoGain.gain.setValueAtTime(0.0, window.lskAudioGraph.context.currentTime);
                }
              }
              
              var audioTrack = window.lskAudioGraph.destination.stream.getAudioTracks()[0];
              var videoTrack = stream.getVideoTracks()[0];
              combinedStream = new MediaStream([videoTrack, audioTrack]);
              
              // Play default background music immediately
              if (!isUseOriginalSound) {
                videoAudioPlayer.currentTime = 0;
                videoAudioPlayer.play();
              }
              
              // Play custom video sound if loaded
              if (isVideoLoaded) {
                videoCardVideo.muted = false; // Let the AudioContext capture the audio
                videoCardVideo.currentTime = videoTrimStart;
                videoCardVideo.play().catch(function(err){ console.log("video play failed:", err); });
              }
              
              // Play custom track exactly 1.0 second later
              if (!isDefaultAudio && !isUseOriginalSound) {
                customAudioPlayer.currentTime = 0;
                window.lskCustomAudioTimer = setTimeout(function() {
                  customAudioPlayer.play();
                }, 1000);
              }
            } catch(e) {
              console.warn('Audio capture/mixing failed, recording silently:', e);
            }
          }
          
          // Prioritize QuickTime & iOS native compatible H.264 MP4 codecs first
          var supportedMime = 'video/mp4;codecs="avc1.424028,mp4a.40.2"';
          if (!MediaRecorder.isTypeSupported(supportedMime)) {
            supportedMime = 'video/mp4;codecs=avc1';
            if (!MediaRecorder.isTypeSupported(supportedMime)) {
              supportedMime = 'video/mp4;codecs=h264';
              if (!MediaRecorder.isTypeSupported(supportedMime)) {
                supportedMime = 'video/mp4';
                if (!MediaRecorder.isTypeSupported(supportedMime)) {
                  // Fallback to WebM if MP4 is not supported on client machine
                  supportedMime = 'video/webm;codecs=vp9';
                  if (!MediaRecorder.isTypeSupported(supportedMime)) {
                    supportedMime = 'video/webm;codecs=vp8';
                    if (!MediaRecorder.isTypeSupported(supportedMime)) {
                      supportedMime = 'video/webm';
                      if (!MediaRecorder.isTypeSupported(supportedMime)) {
                        supportedMime = '';
                      }
                    }
                  }
                }
              }
            }
          }

          var mediaRecorder;
          var chunks = [];
          try {
            if (supportedMime) {
              mediaRecorder = new MediaRecorder(combinedStream, { mimeType: supportedMime, videoBitsPerSecond: 3000000 });
            } else {
              mediaRecorder = new MediaRecorder(combinedStream, { videoBitsPerSecond: 3000000 });
            }
          } catch(e) {
            console.error('MediaRecorder init error:', e);
            mediaRecorder = new MediaRecorder(combinedStream);
          }

          mediaRecorder.ondataavailable = function(e) {
            if (e.data && e.data.size > 0) {
              chunks.push(e.data);
            }
          };

          mediaRecorder.onstop = function() {

            if (videoCardVideo) {
              videoCardVideo.pause();
              videoCardVideo.currentTime = videoTrimStart;
              videoCardVideo.muted = true;
            }
            if (videoPreviewVideo) {
              videoPreviewVideo.currentTime = videoTrimStart;
              videoPreviewVideo.play().catch(function(e) {});
            }
            var blob = new Blob(chunks, { type: supportedMime || 'video/webm' });
            var videoUrl = URL.createObjectURL(blob);
            
            var a = document.createElement('a');
            a.href = videoUrl;
            a.download = 'samsunsondakika-dikey-video.mp4';
            document.body.appendChild(a);
            a.click();
            document.body.removeChild(a);

            setTimeout(function() {
              videoProgressContainer.style.display = 'none';
              selfBtn.disabled = false;
            }, 1000);
          };

          // Generate 20 floating cinematic bokeh particles
          var particles = [];
          for (var i = 0; i < 20; i++) {
            particles.push({
              x: Math.random() * 1080,
              y: Math.random() * 1920,
              radius: Math.random() * 45 + 15,
              speedY: Math.random() * 1.5 + 0.6,
              amplitudeX: Math.random() * 25 + 5,
              frequencyX: Math.random() * 0.0025 + 0.0008,
              phaseX: Math.random() * Math.PI * 2,
              opacity: Math.random() * 0.14 + 0.04
            });
          }

          if (isVideoLoaded && videoCardVideo) {
            videoCardVideo.muted = false;
            videoCardVideo.currentTime = videoTrimStart;
            videoCardVideo.play().catch(function(err){ console.log("video play failed:", err); });
          }

          mediaRecorder.start();

          var duration = videoDuration;
          var elapsed = 0;
          var fps = 29;
          var frameDuration = 1000 / fps;

          function renderNextFrame() {
            var progress = Math.min(1, elapsed / duration);

            // Synchronize the video's currentTime to match the exact frame being drawn
            // Prevent video from playing past the trim end point
            if (isVideoLoaded && videoCardVideo) {
              if (videoCardVideo.currentTime > videoTrimEnd) {
                videoCardVideo.pause();
                videoCardVideo.currentTime = videoTrimEnd;
              }
            }

            // Small delay to allow the browser's video seek and paint pipeline to catch up
            setTimeout(function() {
              requestAnimationFrame(function() {
                ctx.clearRect(0, 0, 720, 1280);

                ctx.save();
                ctx.scale(720 / 1080, 720 / 1080);

                if (isVideoLoaded) {
                  // Draw solid background color
                  ctx.fillStyle = '#0d0d12';
                  ctx.fillRect(0, 0, 1080, 1920);

                  // Draw dynamic video frame with object-fit: contain, zoom, and panning offsets
                  var vWidth = videoCardVideo.videoWidth || 1080;
                  var vHeight = videoCardVideo.videoHeight || 1920;
                  var targetW = 1080;
                  var targetH = 1920;
                  
                  var videoRatio = vWidth / vHeight;
                  var targetRatio = targetW / targetH;
                  
                  var drawW = targetW;
                  var drawH = targetH;
                  var drawX = 0;
                  var drawY = 0;
                  
                  if (videoRatio > targetRatio) {
                    // Video is wider than 9:16 (landscape) -> Fit to width
                    drawW = targetW;
                    drawH = targetW / videoRatio;
                    drawY = (targetH - drawH) / 2;
                  } else {
                    // Video is taller than 9:16 -> Fit to height
                    drawH = targetH;
                    drawW = targetH * videoRatio;
                    drawX = (targetW - drawW) / 2;
                  }

                  var zoomVal = (zoomSlider.value / 100);
                  var panXVal = parseInt(panXSlider.value);
                  var panYVal = parseInt(panYSlider.value);

                  ctx.save();
                  // Clip to full canvas (0, 0, 1080, 1920)
                  ctx.beginPath();
                  ctx.rect(0, 0, 1080, 1920);
                  ctx.clip();
                  
                  // Apply transforms with center origin (540, 960)
                  ctx.translate(540, 960);
                  ctx.scale(zoomVal, zoomVal);
                  ctx.translate(panXVal / zoomVal, panYVal / zoomVal);
                  ctx.translate(-540, -960);
                  
                  // Draw dynamic video frame
                  ctx.drawImage(videoCardVideo, drawX, drawY, drawW, drawH);
                  ctx.restore();

                  // Draw overlays (transparent image renderedCanvas containing text, logo, footer branding)
                  ctx.drawImage(renderedCanvas, 0, 0);

                } else {
                  // 1. Ken Burns Slow Zoom / Cinematic Camera Drift Effect (For static image)
                  var scale = 1 + 0.05 * progress; 
                  var dx = - (1080 * (scale - 1)) / 2;
                  var dy = - (1920 * (scale - 1)) / 2;

                  ctx.save();
                  ctx.translate(dx, dy);
                  ctx.scale(scale, scale);
                  ctx.drawImage(renderedCanvas, 0, 0);
                  ctx.restore();
                }

                // 2. Render Floating Bokeh Particles ( Cinematic Dust / Sparkles )
                particles.forEach(function(p) {
                  var currentY = p.y - p.speedY * (elapsed / 16);
                  if (currentY < -p.radius) currentY = 1920 + p.radius; 
                  
                  var currentX = p.x + Math.sin((elapsed * p.frequencyX) + p.phaseX) * p.amplitudeX;
                  if (currentX < -p.radius) currentX = 1080 + p.radius;
                  if (currentX > 1080 + p.radius) currentX = -p.radius;
                  
                  ctx.save();
                  var grad = ctx.createRadialGradient(currentX, currentY, 0, currentX, currentY, p.radius);
                  grad.addColorStop(0, 'rgba(255, 255, 255, ' + p.opacity + ')');
                  grad.addColorStop(0.5, 'rgba(255, 240, 220, ' + (p.opacity * 0.4) + ')'); 
                  grad.addColorStop(1, 'rgba(255, 255, 255, 0)');
                  ctx.fillStyle = grad;
                  ctx.beginPath();
                  ctx.arc(currentX, currentY, p.radius, 0, Math.PI * 2);
                  ctx.fill();
                  ctx.restore();
                });

                // 3. Diagonal Metallic Glint Shimmer Sweep ( Sweeps every 4 seconds )
                var shimmerProgress = (elapsed % 4000) / 4000;
                var shimmerX = shimmerProgress * 2500 - 500;
                
                ctx.save();
                var shimmerGrad = ctx.createLinearGradient(shimmerX, 0, shimmerX + 400, 1920);
                shimmerGrad.addColorStop(0, 'rgba(255, 255, 255, 0)');
                shimmerGrad.addColorStop(0.5, 'rgba(255, 255, 255, 0.08)'); 
                shimmerGrad.addColorStop(1, 'rgba(255, 255, 255, 0)');
                ctx.fillStyle = shimmerGrad;
                ctx.fillRect(0, 0, 1080, 1920);
                ctx.restore();

                // 4. Ambient pulse vignette glow
                var gradient = ctx.createRadialGradient(540, 960, 500, 540, 960, 1200);
                var glowIntensity = Math.sin(elapsed / 500) * 0.15 + 0.15;
                gradient.addColorStop(0, 'rgba(0,0,0,0)');
                gradient.addColorStop(0.8, 'rgba(0, 92, 151, ' + (glowIntensity * 0.3) + ')');
                gradient.addColorStop(1, 'rgba(54, 55, 149, ' + (glowIntensity * 0.6) + ')');
                ctx.fillStyle = gradient;
                ctx.fillRect(0, 0, 1080, 1920);

                // 5. Timeline bar and text
                ctx.fillStyle = 'rgba(0, 0, 0, 0.6)';
                ctx.fillRect(80, 1780, 920, 16);
                ctx.strokeStyle = 'rgba(255,255,255,0.1)';
                ctx.lineWidth = 2;
                ctx.strokeRect(80, 1780, 920, 16);

                var timelineGrad = ctx.createLinearGradient(80, 0, 1000, 0);
                timelineGrad.addColorStop(0, '#00c6ff');
                timelineGrad.addColorStop(0.5, '#0072ff');
                timelineGrad.addColorStop(1, '#ff007f');
                ctx.fillStyle = timelineGrad;
                ctx.fillRect(80, 1780, 920 * progress, 16);

                ctx.fillStyle = '#ffffff';
                ctx.font = 'bold 22px "Inter", sans-serif';
                ctx.textAlign = 'right';
                ctx.fillText(Math.round(progress * 100) + '%', 1000, 1760);

                ctx.restore();

                var percentVal = Math.round(progress * 100);
                videoProgressBar.style.width = percentVal + '%';
                videoProgressPercent.textContent = percentVal + '%';
                
                var totalSecs = Math.round(duration / 1000);
                videoProgressText.textContent = 'Görüntü işleniyor... (' + Math.round(elapsed / 1000) + '/' + totalSecs + ' saniye)';

                if (progress < 1) {
                  elapsed += frameDuration;
                  renderNextFrame();
                } else {
                  mediaRecorder.stop();
                }
              });
            }, 30);
          }

          renderNextFrame();
        });
      });
    }
  }
});
