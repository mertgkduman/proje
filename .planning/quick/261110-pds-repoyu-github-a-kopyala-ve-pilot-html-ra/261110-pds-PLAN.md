title: Pilot raporu GitHub Pages ile yayımla
---

1. Mevcut Git geçmişini ve dalları `mertgkduman/proje` reposuna aktar. Varsayılan `main` dalını çalışma dalının güncel commit'inden oluştur.
2. `data/current.json` içindeki pilot sürümün HTML dosyasını ve raporun yerel kaynak bağlantılarındaki dosyaları `gh-pages` dalına yerleştir. Site kökünden sürümlü rapora yönlendir.
3. Faz 1 arşiv denetimini, sekmeleri ve kaynak bağlantılarını doğrula. GitHub Pages yayınının durumunu kaydet.
