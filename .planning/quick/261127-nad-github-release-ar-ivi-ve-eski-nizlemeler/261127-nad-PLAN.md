# GitHub arşivi ve çalışma diski

1. Faz 4 tesliminin HTML, JSON, SQLite ve kaynaklarını tek sıkıştırılmış Release varlığına al.
2. Tamamlanmış tarihsel önizlemeleri SHA-256 ile envanterle. Tekrarlanan içerikleri bir kez sakla.
3. Sıkıştırılmış paketleri GitHub Releases üzerinden geri indirip katalog ve dosya özetlerini doğrula. Etkin işlerin dizinlerini koru.
4. Katalogla bire bir eşleşen eski önizlemeleri kaldır. Grup kotasını ve geçerli yayın işaretçisini kontrol et.
5. GitHub Pages üzerinde sıkıştırılmış okuyucuyu ve eski önizleme kataloğunu yayımla.
